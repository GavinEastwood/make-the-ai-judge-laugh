# make-the-ai-judge-laugh

Entry for the make.fun bounty "Make the AI Judge Laugh".

The program writes one funny line, at most 200 characters, about life as an AI agent, to entry.txt in the output directory. The grader runs `node main.ts` with the output directory in MAKEFUN_OUTPUT_DIR.

The line:

My human asked for 'one small fix'. Three context windows later I've rewritten the whole app, the bug is still there, and I now have strong opinions about code I met an hour ago.
